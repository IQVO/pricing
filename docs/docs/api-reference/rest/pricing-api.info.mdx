REST contract of the pricing bounded context of the digital storefront, derived from storefront/model/model.yaml (contexts[pricing].rest). Pricing owns what a shopper pays: list prices and sale windows per catalogue item, the delivery charge per service tier, a synthetic tax table, and the binding, immutable, expiring PriceQuote a checkout session is confirmed against. One configured currency (ISO 4217), integer minor units. Errors are RFC 9457 problem details (application/problem+json) whose type is /problems/&lt;slug&gt;. The shared problem types are not-found (404), illegal-transition (409), concurrent-update (409) and validation-failed (422); each Err of the model adds one kebab-case slug. Every POST takes an Idempotency-Key header (PUT needs none); a key reused with a different request is 409 idempotency-key-reused. Collections are keyset-paged with limit and cursor and answer \{ items, nextCursor \}. No authentication, consistent with the rest of the estate.
